Workflows vs Agents
Two ways to build with Claude, and how to choose
Workflow
Predefined steps. Your code is in charge.
You know the steps in advance, so you hard-code them. Claude does the work inside each step.

Workflow patterns
Four common shapes
Chaining
Break a task into steps. Each call's output feeds the next one.
Routing
Classify the input, then send it down the specialized path.
Parallelization
Run several calls at once, then merge or vote on the results.
Evaluator–optimizer
One call drafts, another grades it. Repeat until it passes.
Agent
A goal and some tools. Claude is in charge.
You don't script the steps. Claude decides what to do next, uses a tool, looks at the result, and keeps going.
EXAMPLE
“Fix the failing test.” Claude reads files, runs the tests, edits code, and repeats until they pass.
